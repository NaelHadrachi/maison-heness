## 🎯 Guide de Sélection du Template par Slug

| Slug | Template | Couleurs |
|------|----------|----------|
| `blog-*`, `article-*` | ARTICLE | Noir/Gris |
| `mentions-legales`, `cgu-*`, `conditions-*` | LEGAL | Gris Formel |
| `boutique-*`, `produit-*` | SHOP | Ambré/Doré |
| `special-*`, `highlight-*`, `featured-*` | FEATURED | Rose/Ambré |
| Autres | DEFAULT | Bleu Neutre |
